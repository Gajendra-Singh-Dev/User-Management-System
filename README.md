# User Management System

A backend User Management System built using Spring Boot, Spring Security, JWT Authentication, MySQL and Maven.

## 📌 Project Overview

The User Management System is a Spring Boot REST API application that provides secure user registration, login and user management functionality.

The application uses JWT-based authentication and BCrypt password encryption to secure user accounts and protected APIs.

## 🚀 Features

- User Registration
- User Login
- JWT Authentication
- BCrypt Password Encryption
- User CRUD Operations
- Role Management
- Email Validation
- Mobile Number Validation
- Password Confirmation
- Duplicate Email Checking
- Global Exception Handling
- MySQL Database Integration
- REST APIs
- Postman API Testing
